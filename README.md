# 🏥 HOSPITAL EMERGENCY ROOM DASHBOARD

## 📊 Hospital Emergency Room Dashboard – Power BI

An interactive **Hospital Emergency Room Dashboard** developed using **Microsoft Power BI** to analyze and visualize emergency room patient data.

The dashboard provides useful insights into **patient admissions, waiting time, patient satisfaction, referrals, admission status, and department-wise performance**. It helps users understand emergency room activities through interactive charts, KPI cards, filters, and multiple dashboard views.

---

## 📌 Dashboard Overview

The dashboard contains multiple views for analyzing hospital emergency room performance.

### 1. 📅 Monthly View

The Monthly View provides a detailed analysis of emergency room activity month by month.

It includes:

- Total Number of Patients
- Average Patient Wait Time
- Patient Satisfaction Score
- Number of Patients Referred
- Patient Admission Status
- Patients Seen Within 30 Minutes
- Monthly Patient Trends
- Department-wise Analysis

---

### 2. 📊 Consolidated View

The Consolidated View provides an overall summary of emergency room performance.

It includes:

- Total Patients
- Average Wait Time
- Patient Satisfaction
- Total Referrals
- Admission Analysis
- Department-wise Performance
- Overall Emergency Room Trends

## 🔄 Data Processing

The hospital emergency room data was processed using **Power Query**.

The main data preparation steps include:

1. Importing the CSV dataset.
2. Cleaning the data.
3. Removing unnecessary or duplicate data.
4. Changing data types.
5. Creating required calculated columns.
6. Creating DAX measures.
7. Building relationships where required.
8. Creating interactive Power BI visualizations.
